# WiFi-Speed-Reconnect

Windows 桌面 WiFi 自动测速 + 智能重连工具。网络卡顿/掉速时，自动测速、断开重连、前后对比评分，保持最优连接。

## 功能

- **自动测速**：每轮测三项 —— 延迟（ping 10 次）、丢包率、下载速度（curl 限时下载 5 秒）
- **智能重连**：断开 → 等待 3 秒 → 重连指定 WiFi → 稳定后再次测速，最多自动尝试 3 次
- **前后对比**：逐轮输出表格对比 信号 / 延迟 / 丢包 / 下载速度 / 综合得分
- **综合评分**：延迟 40% + 下载速度 40% + 信号 20%，自动保留得分最高的连接
- **安全确认**：执行断连前会询问 Y/N，选 N 可只出测速报告不断网

## 文件说明

| 文件 | 用途 |
|---|---|
| `WiFi_Speed_Reconnect.ps1` | 核心脚本（PowerShell，UTF-8 with BOM） |
| `WiFi测速重连.bat` | 双击启动器（自动调用 PowerShell 脚本） |

## 使用方法

1. 先手动连接过一次目标 WiFi（如 `SVIST`），保证系统里已有它的配置文件
2. 双击 `WiFi测速重连.bat` 运行
3. 看到"即将执行断连重连测试"提示时：
   - 输入 `Y`：执行完整流程（断连重连最多 3 次 + 对比报告）
   - 输入 `N`：只输出当前测速报告，不断网
4. 查看对比表格，脚本会提示最优结果

### 只测速不断网（安全模式）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "WiFi_Speed_Reconnect.ps1" -CheckOnly
```

## 配置说明

打开 `WiFi_Speed_Reconnect.ps1` 顶部的"配置区"可修改：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `TargetSSID` | `SVIST` | 目标 WiFi 名称 |
| `PingTargets` | `223.5.5.5` | 延迟测试目标（可改成网关地址） |
| `PingCount` | `10` | 每轮 ping 次数 |
| `SpeedUrls` | 阿里云/腾讯/清华镜像 | 下载测速源，按顺序尝试，第一个能出速度的为准 |
| `SpeedSeconds` | `5` | 每次下载测速时长（秒） |
| `MaxRetry` | `3` | 断连重连最大尝试次数 |
| `ReconnectWait` | `3` | 断开后等待秒数 |
| `ConnectTimeout` | `25` | 等待 WiFi 重新连上的超时秒数 |
| `ScoreW` | 0.4/0.4/0.2 | 综合评分权重（延迟/速度/信号） |

## 评分规则

综合得分 = 延迟分 × 40% + 速度分 × 40% + 信号分 × 20%（0–100 分）。

- 延迟分：丢包 ≥20% 或全部超时记 10 分；≤20ms 记 100 分，每档递减
- 速度分：≥100Mbps 记 100 分；测速源全部不可达记 10 分
- 信号分：≥90% 记 100 分，每档递减

## 已知限制

- 部分网卡驱动（如 Realtek 8922AE）的 `netsh wlan show networks` 不输出各网络信号/频段，脚本会自动降级为只显示网络列表，断连重连由系统自动选择最优 AP
- 校园网/受限网络可能只放行部分测速源（实测 SVIST 网络下仅阿里云镜像可用），脚本会按列表顺序自动尝试
- 脚本只能按 SSID 重连，无法指定连接到某个具体 AP（BSSID）；同一 SSID 多 AP 由 Windows 自动选择

## 适用环境

- Windows 10 / 11（需自带 `curl.exe`，Win10 1803 及以上默认有）
- PowerShell 5.1+
