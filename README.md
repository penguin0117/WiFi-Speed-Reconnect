# WiFi-Speed-Reconnect

Windows 桌面 WiFi 自动测速 + 智能重连工具。网络卡顿/掉速时，自动测速、快速重连（几乎不断网）、逐轮对比评分，保持最优连接。

## 功能

- **自动测速**：每轮测四项 —— 网关延迟、公网延迟（各 ping 10 次）、丢包率、下载速度（限时 5 秒样本）
- **快速重连**：不手动断开，直接触发重新关联（中断约 1~3 秒）；5 秒后公网仍不通才兜底执行完整断开重连
- **轮次策略**：达标即停；不达标依次测满 3 → 6 → 10 轮（3、6 为检查点，默认封顶 10 轮）
- **达标判定**：延迟 >200ms、丢包 >20%、下载速度 <300Mbps 任一命中即判"不达标"并自动重连
- **前后对比**：逐轮输出表格对比 信号 / 延迟 / 丢包 / 下载速度 / 综合得分，最终自动选出**网速最快**的通道
- **综合评分**：延迟 40% + 下载速度 40% + 信号 20%（0~1 连续分）
- **DryRun 模式**：只模拟重连、不断网，用于安全测试

## 文件说明

| 文件 | 用途 |
|---|---|
| `WiFi_Speed_Reconnect.ps1` | 核心脚本（PowerShell，UTF-8 with BOM） |
| `WiFi测速重连.bat` | 双击启动器（自动调用 PowerShell 脚本） |

## 使用方法

1. 先手动连接过一次目标 WiFi（如 `SVIST`），保证系统里已有它的配置文件
2. 双击 `WiFi测速重连.bat` 运行，自动测速三轮，无需确认
3. 查看逐轮对比表格，脚本会提示最佳轮次；若当前连接不如更优轮次，会给出提示

### 可选参数（示例）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "WiFi_Speed_Reconnect.ps1" -MinSpeedMbps 320 -MaxLatencyMs 150 -MaxTries 5
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-MinSpeedMbps` | `300` | 下载速度达标线（Mbps），低于此值判不达标 |
| `-MaxLatencyMs` | `200` | 延迟上限（ms），高于此值判不达标 |
| `-MaxLossPercent` | `20` | 丢包上限（%），高于此值判不达标 |
| `-MaxTries` | `10` | 封顶轮数（不达标依次测满 3→6→10 轮） |
| `-DryRun` | 关 | 只模拟重连不实际断网（用于测试） |

### 只测速不断网（安全模式）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "WiFi_Speed_Reconnect.ps1" -DryRun
```

## 评分规则

综合得分 = 延迟分 × 40% + 速度分 × 40% + 信号分 × 20%（0~1，保留两位小数）。

- **延迟分** = max(0, 1 − 延迟ms / 200)，延迟越高分越低，≥200ms 为 0 分
- **速度分** = min(1, 速度Mbps / 300)，达到 300Mbps 即为满分
- **信号分** = min(1, 信号% / 100)

> 注：评分使用显式 double 计算，规避 PowerShell 5.1 将 `[math]::Max/Min` 绑定到 `(int,int)` 重载、导致小数被四舍五入成 0/1 的失真问题。

## 已知限制

- 部分网卡驱动（如 Realtek 8922AE）的 `netsh wlan show networks` 不输出各网络信号/频段，脚本会自动降级为只显示网络列表，断连重连由系统自动选择最优 AP
- 校园网/受限网络可能只放行部分测速源（实测 SVIST 网络下仅阿里云镜像可用），脚本会按列表顺序自动尝试（阿里云 / 中科大 / 清华镜像）
- 脚本只能按 SSID 重连，无法指定连接到某个具体 AP（BSSID）；同一 SSID 多 AP 由 Windows 自动选择
- 达标线默认 300Mbps：若运营商/校园网出口实际吞吐低于此值，脚本会测满 10 轮后提示最快的通道，可按需调低 `-MinSpeedMbps`

## 适用环境

- Windows 10 / 11（需自带 `curl.exe`，Win10 1803 及以上默认有）
- PowerShell 5.1+
